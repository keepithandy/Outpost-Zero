# Outpost Zero

Outpost Zero is a browser-based survival simulation and the first game built on Pulse Engine.

Players will stabilize a remote outpost by managing resources, time, crew pressure, relationships, and unexpected incidents while the underlying world continues to change.

## Project boundary

Outpost Zero owns its setting, content, interface, progression, balance, and player experience. Reusable simulation behavior belongs in the separate Pulse Engine repository.

## Status

Pre-alpha. The first playable slice and supporting roadmap are tracked through GitHub issues and pull requests.
